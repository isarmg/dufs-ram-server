# 修改当前账号

账号设置作为普通菜单内容页，提供用户名（默认当前用户名）、当前密码、新密码、确认新密码和保存按钮。人物图标保持原样，不增加选中样式或下划线。账号页采用业务内容块的颜色与字体，登录页和账号页均支持浅色、深色主题。

登录管理 Web 后，点击上方菜单栏最右侧的圆形人物图标进入账号页，输入用户名和当前密码。需要修改密码时填写并确认新密码；留空则保留原密码。点击“保存”后，使用新账号信息重新登录，其他浏览器的旧会话也会失效。错误仅显示用户提示，不显示请求标识；失败或离开账号页会清除密码。进入账号页时文件与上传控制器保留，返回“文件”无需重载页面，当前目录和正在进行的上传任务继续保留。

账号名称是登录用户名，不会改变内部账号 ID 或业务数据归属。此入口只修改当前登录账号；系统仅允许一个管理员，不提供创建管理员入口；xszs 的设备备份用户仍可独立管理。

Xczs 将账号修改保存在 `--data-dir` 下的 `administrator/administrator-accounts.json`。文件只包含密码哈希，目录与文件须保留服务用户的私有权限；备份状态目录时包含此子目录。原配置中的账号名用作稳定的引导标识，不要随网页改名而改动配置中的标识。重启会读取已保存账号，配置中的初始密码不会覆盖网页修改。

若忘记管理员密码，停止服务、备份上述账号文件，再将该文件移出状态目录；确认受保护配置中的初始账号及密码哈希有效后重启，将重新采用初始凭据。此操作会同时重置唯一管理员的登录名称及密码，不改变共享文件和上传任务归属。不要在服务运行时编辑账号文件。

会话保持修复：并发请求按不同顺序更新活跃时间时不会再误判退出。正常空闲到期和显式注销仍需重新登录。
