# 修改当前账号

登录管理 Web 后，点击上方菜单栏最右侧的圆形人物图标，输入账号名称和当前密码。需要修改密码时填写并确认新密码；留空则保留原密码。点击“保存账号”后，使用新账号信息重新登录，其他浏览器的旧会话也会失效。

账号名称是登录用户名，不会改变内部账号 ID 或业务数据归属。此入口只修改当前登录账号；系统仅允许一个管理员，不提供创建管理员入口；Media Backup 的设备备份用户仍可独立管理。

Dufs 将账号修改保存在 `--state-dir` 下的 `administrator/administrator-accounts.json`。文件只包含密码哈希，目录与文件须保留服务用户的私有权限；备份状态目录时包含此子目录。原配置中的账号名用作稳定的引导标识，不要随网页改名而改动配置中的标识。重启会读取已保存账号，配置中的初始密码不会覆盖网页修改。

若忘记管理员密码，停止服务、备份上述账号文件，再将该文件移出状态目录；确认受保护配置中的初始账号及密码哈希有效后重启，将重新采用初始凭据。此操作会同时重置唯一管理员的登录名称及密码，不改变共享文件和上传任务归属。不要在服务运行时编辑账号文件。

会话保持修复：并发请求按不同顺序更新活跃时间时不会再误判退出。正常空闲到期和显式注销仍需重新登录。
