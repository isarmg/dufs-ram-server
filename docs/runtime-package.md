# Dufs 运行包

本目录是可直接部署的 Dufs 运行包。它包含服务端二进制、配置与网关样例、许可证、依赖清单、SBOM、构建记录和校验文件。完整源码、开发测试及教学手册位于与 `BUILD-ENVIRONMENT.txt` 中 `source_sha` 对应的项目仓库提交。

部署前先验证包内完整性：

```sh
sha256sum --check SHA256SUMS
./dufs --version
```

复制 `config/dufs.yaml` 并在共享根之外保存实际配置，权限设为 `0600`。先用 `./dufs hash-password` 生成管理员密码哈希，再按环境修改共享根、状态目录和监听地址。浏览器会话要求 HTTPS；生产边界应使用 `deploy/` 中经过项目检查的 systemd 与 nginx 样例，并按实际主机名、证书和回源地址调整。

升级时停止旧进程，备份状态目录和共享根，验证新包与版本，然后原子切换 current 链接并启动服务。确认健康检查、登录、目录读取、上传与下载后再清理旧版本。回滚必须同时恢复与旧二进制匹配的状态备份。
