# Dufs RAM Server 0.51.3

本版本升级到 Foundation Server 0.7.5，并采用 Regular/Bold 两个 Maple 首屏子集。HTML 提前预加载约 328 KiB 的首屏字体，不再为短登录文案请求 18 个分片、约 2.49 MiB。

Web 启动等待从 4 秒缩短到 1.2 秒，不再等待整个 `document.fonts.ready`。等待期间显示不依赖字体的加载指示；字体失败或超时时，本次导航固定使用系统等宽字体，避免后续字体切换。

文件页顶栏改为直接复用 Foundation 的 `PageHeader`：根目录、上传文件、上传文件夹、新建文件夹、新建文件、搜索和刷新均处于统一的全局操作栏；窄屏时仍在同一菜单栏内自动换行，账户设置继续只由右上角人物图标进入。

文件系统健康检查改为读写启动时固定的私有隐藏探针，不再周期性地在共享根目录创建、删除临时项，因此不会无故改变目录时间戳或使有效分页游标失效。
