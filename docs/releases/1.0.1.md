# xczs 1.0.1

## 更新

- 并发上传中部分请求失败或会话失效时，仍为其他正在传输的文件保留离开页面提示。
- 文件夹批量上传不再依赖标签页的动画帧推进，修正后台标签页只接纳前一批文件的问题。
- 目录分页返回时保留正在输入的重命名内容，并避免抢走较新的搜索或重命名输入焦点。
- 创建标签请求返回时保留期间输入的下一条标签草稿。
- 服务端和管理 Web 公共支撑升级到 `xcss 1.0.2`。

## 下载与部署

提供 Linux x86_64 GNU 可执行文件 `xczs-1.0.1-x86_64-unknown-linux-gnu` 和对应 `.sha256`。

安装和运行步骤见[运维文档](../README.md)。
