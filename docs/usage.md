# 文件与标签操作

通过 HTTPS 登录后，顶部有“文件、标签管理、服务状态”三个入口。切换菜单保留当前目录、输入和上传任务；浏览器前进/后退可返回之前的页面。

## 浏览、搜索和下载

在文件页进入目录，使用搜索栏按名称查找。点击单个文件下载；需要进一步筛选时选择“全部、任一、排除”标签条件。
搜索结果继续支持文件操作，先核对所在目录和文件名再修改。

## 上传与续传

选择文件或浏览器支持的文件夹上传，观察每项任务的进度和最终结果。网络中断后按任务提供的继续或确认操作处理。
已存在同名文件时，按界面预检结果确认覆盖。覆盖会替换目标内容，提交前核对名称、位置及冲突提示。

显示“结果未知”时，先查询当前任务和目标文件，不立即提交新的重复操作；持久上传状态会协助确认已有提交。

## 新建、移动、重命名和删除

使用目录页的新建入口或操作菜单。二级菜单中先选择移动、下载、删除、重命名或标签，再点击对应项目。
移动和重命名前确认目标目录；删除会进入服务端持久回收流程，页面没有通用回收站恢复功能。确认目标后再提交。

若提示路径存在活跃上传或清理任务，等待原任务完成后重新发起操作，避免直接从 shell 改动相关路径。

## 添加和筛选标签

1. 在标签管理创建或重命名标签。
2. 回到文件页，选择标签操作并点击普通文件。
3. 在菜单下方的标签行连续点击需要的标签；再次点击已选标签可移除关联。
4. 核对目录表“标签”列，并用搜索栏的标签条件验证筛选结果。

每个文件最多添加 16 个标签；达到上限后，先移除标签再添加。批量添加中任一文件超限时整批不写入。

文件夹不使用标签。手动扫描在“服务状态”中触发；完整扫描成功后才标记缺失文件。文件身份改变时，标签可能需要通过管理接口核对后重新关联。

## 查看服务与修改账号

服务状态显示扫描等运行信息。标签的在线备份只覆盖标签数据库，完整状态与共享文件的维护要求见[运维](operations.md)。
管理员用户名或密码按[账号设置](account-settings.md)修改。保存或上传报错时保留操作 ID，按[故障排查](troubleshooting.md)处理。
